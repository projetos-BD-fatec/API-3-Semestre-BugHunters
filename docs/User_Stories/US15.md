# US15 - Geração do MAPA

## User Story

> Como responsável pelo processo, quero gerar o MAPA com as informações necessárias para dar continuidade à liquidação.

## Critérios de aceitação

- [ ] O MAPA pode ser gerado a partir das guias com pagamento aprovado (US14).
- [ ] Guias que não tiveram o pagamento aprovado não entram no MAPA.
- [ ] O MAPA reúne as informações necessárias para a liquidação (campos definidos com o cliente).
- [ ] O MAPA gerado fica salvo e pode ser consultado depois.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: geração do MAPA com as informações das guias que tiveram o pagamento aprovado.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: reunir as informações de que a liquidação precisa para ser concluída.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: exemplo de MAPA fornecido pelo cliente, com os campos e o formato esperados.
- [ ] As dependências da história estão identificadas: US14 (Aprovação do pagamento).
- [ ] A equipe esclareceu as dúvidas sobre a história. Confirmar com o cliente: qual o formato do MAPA (PDF, planilha ou outro) e quais campos ele deve conter?
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
