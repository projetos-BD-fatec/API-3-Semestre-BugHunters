## User Story

> Como responsável pelo FUSex, quero analisar o encaminhamento médico para identificar os exames e procedimentos necessários.

## Critérios de aceitação

- [ ] O responsável consegue visualizar o encaminhamento registrado e os exames solicitados.
- [ ] O responsável consegue identificar os exames e procedimentos necessários a partir do encaminhamento.
- [ ] O encaminhamento passa a constar como analisado após a análise.
