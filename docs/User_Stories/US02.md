## User Story

> Como responsável pelo FUSex, quero analisar o encaminhamento médico para identificar os exames e procedimentos necessários.

## Critérios de aceitação

- [ ] O responsável consegue visualizar o encaminhamento registrado e os exames solicitados.
- [ ] O responsável consegue identificar os exames e procedimentos necessários a partir do encaminhamento.
- [ ] O encaminhamento passa a constar como analisado após a análise.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: análise do encaminhamento para identificar os exames e procedimentos necessários.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: identificar o que é necessário para o atendimento antes de preparar a Pré-Guia.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: encaminhamentos já registrados (US01) e as regras usadas pelo FUSex para identificar exames e procedimentos, informadas pelo cliente.
- [ ] As dependências da história estão identificadas: US01 (Registro do encaminhamento médico).
- [ ] A equipe esclareceu as dúvidas sobre a história.
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
