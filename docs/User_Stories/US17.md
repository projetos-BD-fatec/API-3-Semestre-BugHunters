## User Story

> Como responsável pelo FUSex, quero acompanhar o status de cada etapa para ter visibilidade do processo desde a solicitação até a liquidação.

## Critérios de aceitação

- [ ] O responsável pelo FUSex consegue consultar o status atual de cada guia, indicando em qual etapa do fluxo ela está (solicitação, emissão, realização, faturamento, Lisura ou liquidação).
- [ ] A listagem pode ser filtrada por status.
- [ ] Ao abrir uma guia, é possível ver as etapas já concluídas e a data de cada uma.
- [ ] Os status exibidos refletem as atualizações feitas nas etapas anteriores do fluxo.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: acompanhamento do status de cada guia ao longo de todo o fluxo, da solicitação à liquidação.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: dar visibilidade de em que etapa cada guia está e do que já foi concluído.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: a lista de etapas e status do fluxo e quais dados de cada guia devem aparecer no acompanhamento.
- [ ] As dependências da história estão identificadas: US01 a US16, pois cada etapa precisa registrar seu status para ele aparecer no acompanhamento.
- [ ] A equipe esclareceu as dúvidas sobre a história. Confirmar com o cliente: o acompanhamento mostra apenas o status atual ou também o histórico de cada etapa?
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
