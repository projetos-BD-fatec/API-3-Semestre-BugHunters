| Prioridade | Sprint | Estimativa | Status |
| :---: | :---: | :---: | :---: |
| Alta | 1 | M | ⬜ |

## User Story

> Como clínica/prestador, quero registrar a realização dos exames para que o atendimento fique registrado no sistema.

## Critérios de aceitação

- [ ] O prestador consegue registrar a realização dos exames de uma guia.
- [ ] O registro informa quais exames foram realizados e a data da realização.
- [ ] Após o registro, a guia passa a constar como realizada.
