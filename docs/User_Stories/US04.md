## User Story

> Como responsável pelo FUSex, quero consultar clínicas e procedimentos disponíveis para identificar o prestador adequado ao atendimento.

## Critérios de aceitação

- [ ] É possível consultar as clínicas disponíveis.
- [ ] É possível consultar os procedimentos realizados por cada clínica.
- [ ] É possível identificar o prestador adequado para os exames de um encaminhamento.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: consulta de clínicas e procedimentos disponíveis.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: identificar o prestador adequado ao atendimento.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: lista de clínicas e dos procedimentos que cada uma realiza, fornecida pelo cliente.
- [ ] As dependências da história estão identificadas: nenhuma; o resultado é usado na Pré-Guia (US05).
- [ ] A equipe esclareceu as dúvidas sobre a história.
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
