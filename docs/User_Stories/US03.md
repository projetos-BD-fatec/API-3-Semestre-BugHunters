# US03 - Consulta à Planilha de Parâmetros

| Prioridade | Sprint | Estimativa | Status |
| :---: | :---: | :---: | :---: |
| Alta | 1 | P | ⬜ |

## User Story

> Como responsável pelo FUSex, quero consultar a Planilha de Parâmetros para obter os dados necessários para o encaminhamento.

## Critérios de aceitação

- [ ] A aplicação exibe os dados da Planilha de Parâmetros armazenados no banco de dados.
- [ ] Os parâmetros consultados podem ser usados no preenchimento do encaminhamento e da pré-guia.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: consulta aos dados da Planilha de Parâmetros.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: ter os parâmetros disponíveis para o preenchimento do encaminhamento e da Pré-Guia.
- [ ] Os critérios de aceitação estão bem definidos e foram validados com o cliente.
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: a Planilha de Parâmetros do cliente, com seu conteúdo e formato.
- [ ] As dependências da história estão identificadas: nenhuma; os dados consultados são usados no encaminhamento e na Pré-Guia (US05).
- [ ] A equipe esclareceu as dúvidas sobre a história. Confirmar com o cliente: o que a Planilha de Parâmetros contém e se ela será importada de um arquivo ou cadastrada manualmente?
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.

## Definition of Done (DoD)

- [ ] A funcionalidade está desenvolvida e integrada ao sistema: dados da planilha armazenados no banco e exibidos na aplicação.
- [ ] Todos os critérios de aceitação foram atendidos.
- [ ] A funcionalidade foi testada: consultar os parâmetros na aplicação e comparar com a planilha original do cliente.
- [ ] Os testes não apresentam erros críticos.
- [ ] A funcionalidade funciona conforme o fluxo definido: parâmetros carregados → consultados durante o preenchimento do encaminhamento e da Pré-Guia.
- [ ] O código está versionado no repositório do projeto.
- [ ] A equipe revisou e validou a entrega.
- [ ] A funcionalidade está pronta para ser apresentada/demonstrada na Sprint Review.
