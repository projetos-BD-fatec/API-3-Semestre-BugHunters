## User Story

> Como responsável pelo FUSex, quero emitir a Guia de Encaminhamento com os dados da solicitação, clínica, procedimentos e valores.

## Critérios de aceitação

- [ ] A Guia FUSex pode ser emitida a partir de uma Pré-Guia.
- [ ] A guia emitida contém os dados da solicitação, a clínica, os procedimentos e os valores.
- [ ] Cada guia emitida recebe um número de identificação único.
- [ ] A guia emitida fica salva e pode ser consultada depois.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: emissão da Guia FUSex com os dados da solicitação, clínica, procedimentos e valores.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: gerar a guia que encaminha o beneficiário para o atendimento na clínica.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: exemplo de Guia FUSex do cliente e a origem dos valores dos procedimentos.
- [ ] As dependências da história estão identificadas: US05 (Preparação da Pré-Guia).
- [ ] A equipe esclareceu as dúvidas sobre a história. Confirmar com o cliente: a guia é emitida pelo nosso sistema ou pelo SIRE (nesse caso, o sistema apenas entrega os dados)?
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
