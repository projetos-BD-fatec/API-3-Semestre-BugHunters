# US12 - Recebimento das faturas

| Prioridade | Sprint | Estimativa | Status |
| :---: | :---: | :---: | :---: |
| Média | 2 | P | ⬜ |

## User Story

> Como responsável pelo FUSex, quero receber digitalmente as faturas enviadas pelas clínicas para dar continuidade ao processo.

## Critérios de aceitação

- [ ] O responsável pelo FUSex consegue visualizar a lista de guias que já têm espelho enviado pela clínica.
- [ ] É possível filtrar a lista por status (utilizadas ou pendentes).
- [ ] A lista exibe os dados necessários para identificar cada guia recebida (número da guia, clínica e situação).

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: consulta, pelo FUSex, das guias com espelho já enviado pela clínica.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: dar visibilidade ao FUSex das faturas recebidas, para que o processo de conferência possa continuar.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: quais dados de cada guia devem aparecer na listagem.
- [ ] As dependências da história estão identificadas: US11 (Envio das guias e documentos).
- [ ] A equipe esclareceu as dúvidas sobre a história.
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
