# US07 - Registro da utilização da Guia

| Prioridade | Sprint | Estimativa | Status |
| :---: | :---: | :---: | :---: |

## User Story

> Como OCS/prestador, quero informar se a Guia foi utilizada ou não para registrar a situação da Guia no sistema.

## Critérios de aceitação

- [ ] A OCS/prestador dispõe de um botão para informar se a guia foi utilizada ou não.
- [ ] A resposta fica registrada e a situação da guia é atualizada no sistema.

## Definition of Ready (DoR)

- [ ] A User Story está claramente descrita: registro, pela OCS/prestador, de que a guia foi utilizada ou não.
- [ ] O objetivo da funcionalidade está compreendido pela equipe: manter atualizada a situação da guia no sistema.
- [ ] Os critérios de aceitação estão bem definidos (ver acima).
- [ ] As informações necessárias para o desenvolvimento estão disponíveis: a decisão validada com o cliente de que a OCS terá um botão para confirmar a utilização da guia e as situações possíveis da guia.
- [ ] As dependências da história estão identificadas: US06 (Emissão da Guia FUSex).
- [ ] A equipe esclareceu as dúvidas sobre a história.
- [ ] A User Story está priorizada no Product Backlog.
- [ ] A equipe consegue estimar o esforço necessário para desenvolvê-la.
