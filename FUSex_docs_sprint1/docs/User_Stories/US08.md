## User Story

> Como responsável pelo FUSex, quero registrar as assinaturas necessárias na documentação para validar o encaminhamento.

## Critérios de aceitação

- [ ] É possível registrar as assinaturas necessárias na guia (médico e chefia do FUSex).
- [ ] Cada assinatura registrada indica quem assinou e quando.
- [ ] A guia só é considerada validada após o registro das assinaturas necessárias.
